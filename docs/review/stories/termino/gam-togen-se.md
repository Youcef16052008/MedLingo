## 1. `termino-case-011` — Le cas de Leila : Ovogenèse (Ovogénèse) anormal(e) / _Leila: the oogenesis is not normal_

**Objectif :** Comprendre des résultats : Gamétogenèse normal(e), Ovogenèse (Ovogénèse) anormal(e).
**Archétype :** case · **Durée :** 10 min · **Statut :** draft

### Récit (segments EN / aide FR / aide AR)
1. **EN** Leila is a patient at the clinic.
   - FR : Leila est un·e patient·e à la clinique.
   - AR : Leila مريض/مريضة في العيادة.
2. **EN** Today, the doctor has the results.
   - FR : Aujourd'hui, le médecin a les résultats.
   - AR : اليوم، الطبيب عنده النتائج.
3. **EN** Amine, a medical student, listens.
   - FR : Amine, étudiant·e en médecine, écoute.
   - AR : Amine، طالب/طالبة طب، يستمع.
4. **EN** The doctor says, “The gametogenesis is normal.”
   - FR : Le médecin dit : « Gamétogenèse est normal(e). »
   - AR : يقول الطبيب: «تكوين الأمشاج طبيعي/طبيعية.»
5. **EN** “But the oogenesis is not normal.”
   - FR : « Mais Ovogenèse (Ovogénèse) n'est pas normal(e). »
   - AR : «لكن تكوين البييضات غير طبيعي/طبيعية.»
6. **EN** Amine asks, “Is the oogenesis normal?”
   - FR : Amine demande : « Ovogenèse (Ovogénèse) est-il/elle normal(e) ? »
   - AR : يسأل Amine: «هل تكوين البييضات طبيعي/طبيعية؟»
7. **EN** The doctor says, “No, it is not.”
   - FR : Le médecin répond : « Non. »
   - AR : يجيب الطبيب: «لا.»

### Expressions ciblées
- `gen:gametogenesis:v1` — **gametogenesis** · FR : Gamétogenèse · AR : تكوين الأمشاج
- `gen:spermatogenesis:v1` — **spermatogenesis** · FR : Spermatogenèse · AR : تكوين الحيوانات المنوية
- `gen:oogenesis:v1` — **oogenesis** · FR : Ovogenèse (Ovogénèse) · AR : تكوين البييضات

### Questions (acceptées / modèle / hint)
- **q1.** Is the gametogenesis normal?
  - accepté : yes ; yes it is ; the gametogenesis is normal ; it is normal
  - modèle : Yes, the gametogenesis is normal.
- **q2.** Is the oogenesis normal?
  - accepté : no ; no it is not ; no it isn't ; the oogenesis is not normal ; it is not normal ; it isn't normal
  - modèle : No, the oogenesis is not normal.
  - hint (si erreur) — FR : Attention : Ovogenèse (Ovogénèse) n'est PAS normal(e).
- **q3.** Which one is not normal: the gametogenesis or the oogenesis?
  - accepté : oogenesis ; the oogenesis
  - modèle : The oogenesis is not normal.
- **q4.** Who has the results?
  - accepté : the doctor ; doctor
  - modèle : The doctor has the results.
- **q5.** Who listens to the doctor?
  - accepté : amine ; the student ; the medical student
  - modèle : Amine listens to the doctor.
- **Tt1.** Is the spermatogenesis normal?
  - accepté : yes ; yes it is ; the spermatogenesis is normal
  - modèle : Yes, the spermatogenesis is normal.
- **Tt2.** Is the gametogenesis normal?
  - accepté : no ; no it is not ; no it isn't ; the gametogenesis is not normal ; it is not normal
  - modèle : No, the gametogenesis is not normal.
  - hint (si erreur) — FR : Attention : Gamétogenèse n'est PAS normal(e) pour ce patient.

### Drill
- Explication : The heart is → The results are. Une chose : is. Plusieurs : are.
- `The gametogenesis … normal. (be)` → is · modèle : The gametogenesis is normal.

- **Tâche :** Annonce les nouveaux résultats, en deux phrases. — modèle : *The spermatogenesis is normal. The gametogenesis is not normal.*
